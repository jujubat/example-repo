## 📊 How It Works - User Journey

### Passenger Tracking a Bus

```
1. Passenger opens app, enters "BUS-001"
   ↓
2. App calls: GET /api/vehicle-tracking/vehicle/BUS-001/status
   ↓
3. System returns:
   {
     "current_location": {"lat": -33.87, "lon": 151.21},
     "status": "in_transit",
     "next_stop": "Central Station in 12 minutes"
   }
   ↓
4. Passenger sees bus on map
   ↓
5. Passenger views full route: GET /vehicle/BUS-001/route
   ↓
6. System returns all stops with ETAs:
   - Central Station: 14:30 (12 min)
   - Town Hall: 14:35 (17 min)
   - Terminal: 14:45 (27 min)
   ↓
7. Traffic incident occurs, driver reports delay
   ↓
8. POST /api/vehicle-tracking/delay/report
   {
     "category": "traffic",
     "duration_minutes": 25,
     "description": "Heavy traffic main road"
   }
   ↓
9. System auto-updates all ETAs (+25 min delay)
   ↓
10. If passenger offline, notification queued locally
    When online, notification delivered automatically
```

### Stop Added Mid-Journey

```
1. Operator adds new stop at sequence 3
2. RouteStopManager.add_stop(...)
3. Stops 3+ automatically shift to 4+
4. All passengers notified of new stop
5. Next vehicle has stop in sequence
6. Route display updated for all querying passengers
```

### Weather-Related Delay

```
1. Heavy rain starts affecting buses
2. Dispatch posts: POST /delay/report
   - category: "weather"
   - duration: 45 min
   - impact: +10 min travel time
3. System adds weather delay factor
4. All ETA calculations include +10 min
5. Confidence scores reduced (weather = less predictable)
6. All affected passengers notified
7. Notifications queue if offline
8. Sync when connection restored
```

## 📝 Usage Examples

### Example 1: Track a Bus
```python
from batuma_gprs_weather.transit.real_time_tracking import RealTimeTrackingSystem

tracking = RealTimeTrackingSystem()
tracker = tracking.register_vehicle("BUS_001", "BUS-001", "bus", "ROUTE_5")

# Receive GPS update
tracking.update_vehicle_location("BUS_001", -33.8688, 151.2093, speed_kmh=45.5)

# Get current location
location = tracker.get_current_location()
# {"latitude": -33.8688, "longitude": 151.2093, "status": "in_transit"}
```

### Example 2: Calculate ETA
```python
from batuma_gprs_weather.transit.eta_calculator import ETACalculator

calc = ETACalculator("ROUTE_5", "BUS_001")
calc.add_stop_sequence(stops_data)
calc.add_delay_factor("traffic", 30, 15)  # 30 min incident, +15 min impact

etas = calc.calculate_eta_for_all_stops()
# [{"stop_name": "Central", "arrival": "14:30", "delay": 8, "confidence": 87}]
```

### Example 3: Report Delay
```python
from batuma_gprs_weather.transit.delay_reporting import DelayReportingSystem

delays = DelayReportingSystem()
report = delays.report_delay(
    "BUS_001", "BUS-001", "traffic", 25, 
    "Heavy traffic on main road"
)

# Notifications auto-created for affected passengers
# Queued offline if needed, synced when online
```

### Example 4: Add Stop Mid-Journey
```python
from batuma_gprs_weather.transit.stop_management import RouteStopManager

manager = RouteStopManager("ROUTE_5", "City Express", "bus")
# ... existing stops 1-10

# Add new stop at position 5
new_stop = manager.add_stop(
    "New Station", 
    {'lat': -33.87, 'lon': 151.21},
    "station",
    sequence_number=5,
    estimated_stop_time_minutes=5
)

# Stops 5-10 now become 6-11 automatically
```
